Important gameplay-completion note

This setup deliberately does not mark nebula_gameplay_ended as a key event because that event can also represent failure, quit, or restart. Later, emit a dedicated nebula_song_completed event (or create a derived event for outcome=completed) and mark that as a key event instead. Counting quits as successful completions would produce beautifully polished nonsense.
